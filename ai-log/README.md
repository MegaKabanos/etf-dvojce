# AI log

Přepis práce s AI nástroji (Claude Code) na projektu Dvojče.

- `00-full-session.md` — kompletní přepis celé session. Vygenerovaný skriptem `scripts/export-transcript.mjs` ze session souboru Claude Code (`.jsonl`). Obsahuje všechny uživatelské zprávy a odpovědi modelu v chronologickém pořadí; volání nástrojů jsou zobrazena jako jednořádkové souhrny, systémové a kontextové vstupy jsou odstraněny, citlivé údaje jsou zredigované.
- `01-build.txt` — originální `/export` z Claude Code. Obsahuje jen poslední část session, protože dřívější kontext byl při komprimaci zkrácen.
